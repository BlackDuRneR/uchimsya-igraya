# Рядом

Android-приложение для семьи: витамины, лекарства, курсы, остатки и привычки,
общие для супругов и детей. Слоган: «Забота, которая не забывается».

Этот каталог не связан с соседним проектом «Учимся играя» в корне репозитория
и его не затрагивает.

## Статус

| Этап | Содержание | Статус |
|---|---|---|
| 1 | Дизайн-концепция: направление, цвет, шрифты, логотип, иконки, иллюстрации, компоненты, карта экранов | **готово, ждёт утверждения** |
| 2 | UX-прототип: все экраны и навигация на Compose, временные данные | не начат |
| 3 | Основная функциональность: профили, препараты, расписание, отметки, история, курсы, остатки (Room) | не начат |
| 4 | Напоминания: AlarmManager, действия из уведомления, перезагрузка, часовые пояса | не начат |
| 5 | Семья и синхронизация: Firebase Auth, Firestore, приглашения, FCM через Cloud Functions | не начат |
| 6 | Финальная полировка дизайна, тёмная тема, виджеты | не начат |
| 7 | Тестирование по 18 сценариям ТЗ, сборка APK/AAB | не начат |

## Что есть сейчас

```
design/
  concept.html            страница концепции (собирается автоматически, открыть в браузере)
  concept.src.html        шаблон страницы
  tokens/tokens.json      дизайн-токены: цвета обеих тем, шрифты, шкала, отступы, радиусы, движение
  assets/icons/           63 иконки, сетка 24, линия 1.75
  assets/illustrations/   20 иллюстраций × светлая и тёмная тема (SVG, 240×180)
  assets/logo/            знак, иконка приложения, слои adaptive icon, иконка уведомления
  reference/              присланный эскиз иконки (для сравнения)
  tools/build.py          генератор всего перечисленного
```

Пересобрать ассеты и страницу:

```bash
python3 design/tools/build.py
```

Все иконки, иллюстрации и знак нарисованы кодом в `design/tools/*.py`, поэтому
стиль един по построению: одна толщина линии, одна палитра, один приём
«смещённой печати». Чтобы поменять цвет во всей графике, достаточно изменить
`design/tools/palette.py`. Сторонних картинок и стоков нет.

## Ключевые решения

**Шрифты.** Source Serif 4 (заголовки, приветствие, крупные числа) и Onest
(интерфейс). Оба шрифта под лицензией OFL, поддерживают казахские буквы
и будут вшиты в APK, а не загружаться из сети.

**Контраст.** Text Secondary `#818780` на фоне `#F6F5F0` даёт 3,4:1, а это ниже
нормы WCAG для мелкого текста. Предложение: подписи до 18 sp делать `#666C65`
(4,9:1), исходный цвет оставить для иконок и крупного текста. Текст на кнопках
использует Primary Dark, а не Primary. Нужно согласие заказчика.

**Логотип «Ладони».** Две полудуги (двое взрослых) держат точку (того, о ком
заботятся). Альтернативы «Под одной крышей» и «Рука об руку» показаны на
странице концепции.

**Архитектура (этапы 2–5).**
- Kotlin, Jetpack Compose, собственная тема поверх Material 3, MVVM + слой данных.
- Модули: `app`, `core:designsystem`, `core:model`, `core:database` (Room),
  `core:data` (репозитории и синхронизация), `core:notifications`,
  `feature:{home,schedule,family,history,medication,settings,onboarding}`, `widget` (Glance).
- Офлайн по умолчанию: Room — источник правды, изменения копятся в очереди
  и уходят в Firestore при наличии сети.
- ID отметки приёма = `medicationId + плановое время`. Одновременные отметки
  двух родителей сходятся в одну запись, дублей нет.
- История неизменяема. Правка расписания не переписывает прошлое,
  удаление препарата — это архив (soft delete).
- Напоминания: `AlarmManager.setExactAndAllowWhileIdle` при разрешении
  SCHEDULE_EXACT_ALARM, иначе неточный будильник с понятным объяснением
  в настройках. Перепланирование после перезагрузки, смены часового пояса
  и времени. Абсолютную точность ОС не гарантирует, и приложение это не обещает.
- Семейные push-уведомления другому телефону требуют серверной части:
  Firebase Cloud Functions, а значит, тариф Blaze.

## Нужно от заказчика до этапа 2

1. Выбрать логотип.
2. Согласовать цвет подписей (см. «Контраст»).
3. Создать проект Firebase (или поручить это разработчику) и подтвердить тариф Blaze для семейных push.
4. Решить, остаётся ли проект в этой папке или переезжает в отдельный репозиторий.
