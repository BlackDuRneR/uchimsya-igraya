# Рядом

Android-приложение для семьи: витамины, лекарства, курсы, остатки и привычки,
общие для супругов и детей. Слоган: «Забота, которая не забывается».

## Статус

| Этап | Содержание | Статус |
|---|---|---|
| 1 | Дизайн-концепция: направление, цвет, шрифты, логотип, иконки, иллюстрации, компоненты, карта экранов | готово, утверждено |
| 2 | UX-прототип: все экраны и навигация на Compose, данные на телефоне | **готово** |
| 3 | Room вместо файлового хранилища, привычки, перенос данных | не начат |
| 4 | Напоминания: AlarmManager, действия из уведомления, перезагрузка, часовые пояса, виджеты | не начат |
| 5 | Семья и синхронизация: Firebase Auth, Firestore, приглашения, FCM через Cloud Functions | ждёт проект Firebase |
| 6 | Финальная полировка дизайна | не начат |
| 7 | Тестирование по 18 сценариям ТЗ, сборка APK/AAB | не начат |

### Решения, принятые с заказчиком

- Логотип — «Ладони».
- Подписи мельче 18 sp — цвет `#666C65` (контраст 4,9:1); `#818780` — для иконок и крупного текста.
- Firebase-проект создаёт заказчик, остальное настраивается через GitHub Actions с ключом сервисного аккаунта в секретах репозитория.
- Проект переезжает в отдельный репозиторий `ryadom`.

## Что работает на этапе 2

Это реальное приложение, а не набор картинок: все кнопки выполняют действие.

- Вход: приветствие, регистрация, создание семьи, пример семьи («Посмотреть пример»).
- Главная: приветствие, прогресс семьи, блок «Сейчас», сообщение от супруга, предупреждения об остатке и конце курса, приёмы по утру/дню/вечеру.
- Отметка в одно касание (круг справа), анимация и тактильный отклик; лист действий: позже на 5/15/30 минут или к своему времени, пропустить, отменить на сегодня, сообщение второму взрослому.
- Расписание: день, неделя, месяц (календарь), фильтр по человеку, курсы.
- Препарат: добавление и редактирование (дозировка, дни, время, курс, кто следит, напоминания, остаток, заметки, фото упаковки), карточка, архив, удаление с сохранением истории, завершение курса.
- Остатки: прогноз в днях, «купили упаковку», ручная правка, история пополнений.
- Семья: участники, профиль ребёнка, взрослый без аккаунта, роли, передача владения, исключение, код приглашения, семейные сообщения.
- История и статистика по дням, людям и препаратам за неделю, 2 недели, месяц или выбранный период.
- Настройки: уведомления (звук, вибрация, тихие часы, правила семейных уведомлений), напоминания и разрешения Android, синхронизация, тема, язык (RU/KK/EN), экспорт данных в JSON, выход из семьи, удаление семьи и аккаунта.
- Состояния: пустые экраны, скелетоны загрузки, плашка «нет сети» (реальная проверка сети), ошибки с понятным текстом.

### Чего пока нет и почему

| Что | Когда |
|---|---|
| Уведомления реально не приходят: экран «Напоминания» показывает расписание и разрешения | этап 4 |
| Синхронизация между телефонами, вход в существующий аккаунт, вход по коду приглашения | этап 5 (нужен Firebase) |
| Данные хранятся в файле JSON на телефоне; при выходе из аккаунта удаляются | этап 3 переносит в Room, этап 5 — в облако |
| Виджеты на рабочий стол | этап 4 |
| Раздел «Мои привычки» | модель готова, экраны — этап 3 |

## Архитектура

```
app/                    Activity, заставка, тема, корневая навигация
core/model              Чистый Kotlin: модели и движок расписания (unit-тесты)
core/data               Хранилище, репозитории, сеть, настройки (DataStore), Hilt-модули
core/designsystem       Тема, токены, шрифты, 63 иконки, 20 иллюстраций, компоненты
core/ui                 Общие экраны-элементы: строка приёма, лист действий, форматирование
core/l10n               Все строки: values (RU), values-en, values-kk
feature/onboarding      Вход и создание семьи
feature/home            Главная
feature/schedule        Расписание, календарь, напоминания
feature/family          Семья, профили, приглашения, сообщения
feature/history         История и статистика
feature/medication      Препарат: добавление, карточка, остатки, курс
feature/settings        Настройки
design/                 Концепция, токены, исходники графики и генератор
```

- MVVM: экран → ViewModel → репозитории (`core/data`) → хранилище. UI не знает о хранилище.
- Фичи не зависят друг от друга, связываются только в `app` через навигацию.
- Офлайн по умолчанию: всё пишется локально; на этапе 5 добавится очередь отправки в Firestore.
- ID отметки = препарат + плановое время, поэтому одновременные отметки двух родителей не создают дублей.
- История неизменяема: правка расписания её не трогает, удаление препарата — мягкое.

Стек: Kotlin 2.2, Jetpack Compose (Material 3 только как основа), Hilt, Navigation Compose с типобезопасными маршрутами, Coroutines/Flow, DataStore, kotlinx.serialization. minSdk 26, target 36.

## Сборка

Нужны JDK 17+ и Android SDK 36.

```bash
./gradlew assembleDebug                 # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew :core:model:test              # тесты движка расписания
./gradlew :app:recordRoborazziDebug     # сквозной прогон приложения и снимки экранов в design/screenshots
python3 design/tools/build.py           # пересобрать иконки, иллюстрации, логотип и страницу концепции
```

Графика (иконки, иллюстрации, знак, иконка приложения, заставка) генерируется из `design/tools/*.py`
в SVG и Android VectorDrawable. Вручную векторы не редактируются.

Шрифты Source Serif 4 и Onest вшиты в приложение, лицензия OFL — `design/licenses/`.
Казахский перевод подготовлен разработчиком и требует проверки носителем языка до публикации.
